## Sobre o projeto

Este repositório contém o meu site pessoal, desenvolvido como **Trabalho Prático Semestral #1** da disciplina de Desenvolvimento Web (UNIFAL-MG).

O site foi criado com **WordPress** e exportado como conteúdo estático usando o plugin [Simply Static](https://wordpress.org/plugins/simply-static/). Os arquivos gerados são publicados gratuitamente pelo **GitHub Pages**.

## Tecnologias

- WordPress (criação e edição do conteúdo)
- Simply Static (geração do site estático)
- HTML, CSS e JavaScript
- GitHub Pages (hospedagem)

## Como funciona a publicação

1. O site é construído e editado localmente no WordPress.
2. O plugin Simply Static gera os arquivos estáticos (HTML, CSS, JS e imagens).
3. Os arquivos gerados são enviados para a branch `main` deste repositório.
4. O GitHub Pages publica automaticamente o conteúdo da raiz (`/`) da branch `main`.

## Estrutura do repositório

```
.
├── index.html      # Página inicial
├── wp-content/     # Temas, plugins e arquivos de mídia exportados
├── wp-includes/    # Recursos do WordPress exportados
└── README.md       # Este arquivo
```

> A estrutura pode variar conforme a exportação do Simply Static.


A publicação leva de 1 a 3 minutos para refletir as mudanças.
